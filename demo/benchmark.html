Vector interop benchmark

The same source bytes, read once per path by the same pure-Rust engine, delivered to JavaScript three different ways. What is being measured is the handoff: how long until the main thread holds coordinates a GPU could draw.

GeoJSON is the historical path — WASM returns a string, JS parses it, then the app flattens the parsed objects into typed arrays. Binary returns deck.gl's binary attribute layout directly. Arrow IPC returns a GeoArrow record batch for apache-arrow / DuckDB-WASM / @geoarrow/deck.gl-layers.

Generated points mimic the case from issue #31: many points, wide attribute table.
